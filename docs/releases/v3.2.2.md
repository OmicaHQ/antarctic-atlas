# Antarctic Atlas v3.2.2 — Drag-to-Install for Apple Silicon

v3.2.2 turns the stable Apple Silicon app into a standard Mac installation
experience. Open the DMG, drag Antarctic Atlas to Applications, eject the disk
image, and launch the installed app. The complete 89-page Noble et al. (2020)
review paper remains included.

## Install

1. Double-click the DMG.
2. Drag `Antarctic Atlas.app` onto the `Applications` shortcut.
3. Eject `Antarctic Atlas 3.2.2`.
4. In Applications, Control-click Antarctic Atlas and choose **Open**.
5. Confirm **Open** when macOS asks.

- Added the standard `/Applications` drag target and a custom disk icon.
- Added fixed icon placement, a clear install arrow, and Apple Silicon system

- Preserved verified DMG and ZIP artifacts in GitHub Actions for release review.

## System requirements and signing

- Apple Silicon (`arm64`) Mac; Intel Macs are not supported.
- macOS 15.0 or later.
- No Python installation is required.

The app is ad-hoc signed, not signed with an Apple Developer ID, and not
notarized by Apple. The DMG improves installation and presentation but does not
remove Gatekeeper's first-open approval. Only download it from this repository's
official release page.
