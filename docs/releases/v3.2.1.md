# Antarctic Atlas v3.2.1 — Apple Silicon Stable

This is the first stable Mac release of Antarctic Atlas. It is a self-contained
native `arm64` app for Apple Silicon Macs and includes the complete 89-page
Noble et al. (2020) Antarctic Ice Sheet review paper.

## What improved since the preview

- Fixed app-close and language-restart crashes while background work is active.
- Isolated DeepSeek and OpenAI credentials so one provider's key can never be
  reused for the other. Keys remain in memory for the current run only.
- Made provider changes interrupt active workers and reject stale classification,
  answer, and connection-test results. Local Ollama no longer reads online API
  credentials.
- Fixed Chinese Evidence-only topic matching, including grounding-line retreat,
  ice-shelf basal melt, CDW intrusion, and GRACE.
- Corrected paper retrieval: science pages 1–63 remain searchable evidence and
  the pure References section on pages 64–89 no longer dominates results.
- Centered visible evidence and optional AI context on the actual keyword match.
- Corrected Mini Lab temperature physics and snowfall units.
- Restored the Antarctic System summary, all Mini Lab diagnoses, Return-to-search
  in Raw Paper, and reliable proposal export errors.
- Added About/version/help UI, completed Chinese graph and System-summary
  labels, safe JSON paper caching,
  dependency security updates, license notices, and a macOS Apple Silicon CI
  build gate.

## System requirements and first launch

- Apple Silicon (`arm64`) Mac; Intel Macs are not supported.
- macOS 15.0 or later.
- No Python installation is required.

This build is ad-hoc signed, not signed with an Apple Developer ID, and not
notarized by Apple. On first launch, Control-click `Antarctic Atlas.app` in
Finder, choose **Open**, then confirm **Open**. Only download it from this
official repository release.

## Privacy

Evidence-only mode is local, offline, and has no telemetry. Local Ollama sends
data only to the local Ollama service. If DeepSeek or OpenAI is selected, the
question and locally retrieved paper passages are sent to that selected
provider. API keys entered in the app are not persisted.
