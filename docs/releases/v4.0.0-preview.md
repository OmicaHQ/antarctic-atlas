# Antarctic Atlas v4.0.0 Preview — Native Apple Silicon Client

This GitHub Pre-release is the first public build of the next-generation
SwiftUI/AppKit macOS client. It targets Apple Silicon Macs running macOS 15 or
later and installs as `Antarctic Atlas Native Preview.app`, alongside the
stable Qt-based v3.2.2 app.

## What changed

- Rebuilt Research Universe as a native SwiftUI canvas with the original
  Windows-era colored translucent orbs, centered labels on each sphere,
  hierarchy-aware focus transitions, flowing links, AI pulse, and breathing
  core.
- Added collision-aware placement and coordinate-aware circular hit testing so
  packed spheres remain easy to select without neighboring misfires.
- Removed the bright rectangular keyboard focus halo from the graph while
  retaining keyboard navigation and full Reduce Motion behavior.
- Restored source-like interaction and motion in System Explorer, AI Visualizer,
  Mini Research Lab, Research Directions, and the PDF reader.
- Removed the misleading synthetic Mini Research Lab trend chart; the result
  view now presents the selected scene, diagnosis, and measured metrics in a
  direct, legible hierarchy.
- Kept the complete 89-page Noble et al. (2020) review paper bundled locally;
  Evidence-only mode remains offline by default.

## Install and first launch

1. Open the DMG.
2. Drag `Antarctic Atlas Native Preview.app` to the `Applications` shortcut.
3. Eject the `Antarctic Atlas 4.0.0 Preview` disk image.
4. In Applications, Control-click the preview app and choose **Open**.
5. Confirm **Open** when macOS asks.

This preview is ad-hoc signed, not signed with an Apple Developer ID, and not
notarized by Apple. If Gatekeeper still blocks it, use **System Settings >
Privacy & Security > Open Anyway** after the first attempted launch.

## Compatibility and coexistence

- Apple Silicon (`arm64`) only; Intel Macs are not supported.
- macOS 15.0 or later.
- No Python installation is required.
- The preview uses a separate bundle identifier and app name, so it can remain
  installed beside the stable v3.2.2 Qt client.

## Validation

- The optimized app bundle passes strict ad-hoc signature verification and

- The DMG is verified, mounted, checked for the two expected Finder entries,
